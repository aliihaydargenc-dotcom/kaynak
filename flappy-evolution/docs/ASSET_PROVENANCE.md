# Asset provenance
All product assets are original procedural/vector drawings authored for this repository, 2026-11-09. No example sprites, stock images, external fonts or remote audio.
- src/game/systems/AssetFactory.ts: four 480×854 sky/terrain backgrounds, four 960×250 parallax silhouettes, four 96×520 pillar bodies and 108×24 caps, 64×64 coin. New Canvas 2D paths, gradients and landscape geometry.
- Same file: spark/sprout/dune/crystal/nova, each three 72×64 animation frames. Distinct crest and wing details. Texture envelope and anchor deliberately retain upstream Bird hitbox contract; ?debug draws actual rotated hitbox and pipe collision rectangles.
- public/icons/hero.svg: original illustrated Kıvılcım and flight marks; public/icons/skin-*.svg: original wardrobe thumbnails.
- src/ui/icons.ts: original consistent 24×24 SVG UI path set.
- public/icons/icon.svg and PNG normal/maskable icons: original Kıvılcım-derived app mark. Generated by scripts/generate-icons.cjs using Chromium SVG rasterization.
- AudioSystem: original synthesized sine/triangle frequency recipes (flap 360→570, score 620→830, coin 980→1460, impact 170→55, unlock 520→1040 Hz); upstream oscillator/gain envelope technique adapted under its retained MIT notice.
- No mola-app application code copied. UI/UX Pro Max was consulted as guidance; no code/data from that skill ships in the game.
